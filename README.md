# Asynchrony-FIFO
Parameterized asynchronous FIFO in SystemVerilog with gray-code pointers and 2-flop CDC synchronizers. Verified with directed/random testbenches, SVA assertions, and formal methods (SymbiYosys). Synthesized for Gowin GW1NR-9 (Tang Nano 4K).
